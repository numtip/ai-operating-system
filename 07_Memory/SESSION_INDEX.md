## Format

| Column | Meaning |
|--------|---------|

## Protocol

- Add a row at session close ([SESSION_CLOSE](SESSION_CLOSE.md))
- File name: `sessions/YYYY/YYYY-MM-DD-topic.md`
- Status overview: [CURRENT_STATE](CURRENT_STATE.md)
